## One-line definition

AIGMos is a local-first orchestration and control runtime / AI realtime OS built around one symbolic command surface.

## Hard rule

Do not explain AIGMos primarily as a chat framework.
`q` and `qc` are AI-facing modules inside the larger runtime, not the product definition.
