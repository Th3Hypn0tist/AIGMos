# What AIGMos Is Not

Use this file to avoid recurring misclassifications.

## Not primarily a chat framework

Chat is one interface layer.
It is not the main product definition.

## Not just a shell for q

`q` is one module family.
AIGMos also includes state, events, triggers, runners, layouts, routing, and external IO.

## Not just a database

The symbolic state model matters, but AIGMos is an execution runtime, not only storage.

## Not only automation rules

Triggers and events matter, but AIGMos is not only a rule engine.

## Not a static UI toolkit

Layouts matter, but the system is not merely a renderer.

## Safer replacement sentence

Instead of:

```text
AIGMos is a chat interface framework.
```

Use:

```text
AIGMos is a symbolic orchestration runtime / AI realtime OS with chat as one operator-facing interface.
```
