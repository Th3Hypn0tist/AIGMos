# Events

## What `@` is

`@` is an event object.

An event is a dispatchable command binding, not a trigger, not a runner, and not a persistent process.

## Short model

```text
trigger fires -> event is emitted -> parser executes command
```

## Core rule

One event represents one command dispatch unit.
