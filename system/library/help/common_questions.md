# Common Questions

## What is AIGMos in one sentence?

AIGMos is a local-first symbolic orchestration runtime / AI realtime OS built around one command surface.

## Is it only for chat?

No.
Chat is one interface layer inside the runtime.

## What are q and qc?

AI modules used inside the larger runtime.

## What does `|` mean?

A layout instance root and its instance-owned runtime space.

## What does `@` mean?

An event dispatch object.

## What does `!` mean?

A trigger object.

## What does `%` mean?

A runner object.
