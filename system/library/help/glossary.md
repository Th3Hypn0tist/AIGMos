# Glossary

## command surface
The explicit symbolic control interface of the runtime.

## layout instance
A `|` root containing instance-owned runtime data.

## trigger
A `!` object that gates or detects when something should fire.

## event
An `@` object that represents a command dispatch unit.

## runner
A `%` object that executes work over time.

## think
Payload intent for q.

## stream
Transport gate for q.

## view_thinking
UI-only visibility flag for q thinking display.
